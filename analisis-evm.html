¿Qué hace? Define licencia MIT, versión del compilador ^0.8.24 e importa módulos auditados de OpenZeppelin v5.1.

Compilación: Los import se resuelven en tiempo de compilación. No generan opcodes de runtime propios, pero el bytecode resultante incluye inline el código de las librerías heredadas (no usa DELEGATECALL a librerías externas).

Herencia (C3 Linearization): El orden de herencia determina el layout de storage. Por ejemplo, en ConsorcioVotes: ERC721, EIP712, ERC721Votes, Ownable2Step. Ownable2Step hereda de Ownable (slots 0-1), luego vienen los campos del ERC721 estándar.

ConsorcioVotes.sol (NFT Soulbound + ERC721Votes)

contract ConsorcioVotes is ERC721, EIP712, ERC721Votes, Ownable2Step { bool public transferenciasHabilitadas; bool private _reasignacionAutorizada; mapping(uint256 => uint256) public cuotaParteDeUnidad; function adjudicarUnidad(uint256 unidadId, address vecino, uint256 cuotaParte) external onlyOwner { if (vecino == address(0)) revert DireccionInvalida(); if (cuotaParte == 0) revert CuotaParteInvalida(); address propietarioActual = _ownerOf(unidadId); if (propietarioActual != address(0)) revert UnidadYaAsignada(unidadId, propietarioActual); cuotaParteDeUnidad[unidadId] = cuotaParte; _mint(vecino, unidadId); if (delegates(vecino) == address(0)) { _delegate(vecino, vecino); } emit UnidadAdjudicada(unidadId, vecino, cuotaParte); } }

Función Selector: bytes4(keccak256("adjudicarUnidad(uint256,address,uint256)")) = 0x4e1b5b6c.

Soulbound: El override de _update() bloquea transferencias entre particulares (solo admite mint, burn o reasignación autorizada por owner).

Auto-delegación: El _delegate(vecino, vecino) activa el poder de voto sin necesidad de otra tx. Esto registra un checkpoint en ERC721Votes._checkpoints con el snapshot de voting power al timestamp actual.

tokenId == unidadId: Cada NFT representa 1 unidad funcional. No hay dos NFTs con el mismo ID (garantiza 1 vecino = 1 voto).

Gas: Mint + SSTORE en mappings de cuota + checkpoint = ~55k gas. Mucho menor que ERC20Votes (~80k) por no requerir doble burn/mint en compraventas.

ConsorcioTimelock.sol (TimelockController + Sellado Atómico)

contract ConsorcioTimelock is TimelockController { bool public gobernanzaSellada; function configurarYSellarGobernanza(address governor) external onlyRole(DEFAULT_ADMIN_ROLE) { if (governor == address(0)) revert DireccionGovernorInvalida(); if (gobernanzaSellada) revert GobernanzaYaSellada(); gobernanzaSellada = true; _grantRole(PROPOSER_ROLE, governor); _grantRole(CANCELLER_ROLE, governor); _grantRole(EXECUTOR_ROLE, governor); _grantRole(EXECUTOR_ROLE, address(0)); // ejecución pública renounceRole(DEFAULT_ADMIN_ROLE, msg.sender); // ¡irreversible! emit GobernanzaConfiguradaYSellada(governor, msg.sender); } }

Function Selector: bytes4(keccak256("configurarYSellarGobernanza(address)")) = 0xb3a.collect → 0xb3ac1b1e.

Roles AccessControl: PROPOSER_ROLE = keccak("PROPOSER_ROLE"), CANCELLER_ROLE = keccak("CANCELLER_ROLE"), EXECUTOR_ROLE = keccak("EXECUTOR_ROLE"). Cada hasRole() lee desde _roles[role][account].

Sellado Atómico: En UNA sola tx, se asignan 4 roles (PROPOSER+CANCELLER+EXECUTOR al governor, EXECUTOR a address(0) para que cualquiera pueda ejecutar tras el delay) Y se revoca DEFAULT_ADMIN_ROLE del deployer.

Storage (AccessControl): El mapping _roles está en slot heredado de AccessControl. gobernanzaSellada es una variable propia adicional.

Gas: 4 × SSTORE (cada grant) + 1 SSTORE (revocar admin) + 1 SSTORE (gobernanzaSellada) = ~120,000 gas solo en storage.

Seguridad post-sellado: El deployer no puede volver a obtener DEFAULT_ADMIN_ROLE. Esto mitiga el hallazgo CD-07 de la auditoría.

ConsorcioGovernor.sol (Gobernanza OpenZeppelin)

contract ConsorcioGovernor is Governor, GovernorSettings, GovernorCountingSimple, GovernorVotes, GovernorVotesQuorumFraction, GovernorTimelockControl { constructor(IVotes _token, TimelockController _timelock, uint48 _votingDelay, uint32 _votingPeriod, uint256 _proposalThreshold, uint256 _quorumPercentage) { if (_votingPeriod == 0) revert PeriodoVotacionInvalido(); if (_quorumPercentage < QUORUM_MINIMO || _quorumPercentage > QUORUM_MAXIMO) revert QuorumInvalido(_quorumPercentage); } } // Flujo de uso runtime: // 1. propose(targets, values, calldatas, description) → proposalId = hash(targets,values,calldatas,keccak(desc)) // 2. castVote(proposalId, support) → lee voting power en snapshot(clock - votingDelay) // 3. queue(targets, values, calldatas, descHash) → Timelock.scheduleBatch() // 4. execute(targets, values, calldatas, descHash) → Timelock.execute() → CALL a ConsorcioObras

Selectores principales:

ConsorcioObras.sol (Vault + Máquina de Estados)

contract ConsorcioObras is ReentrancyGuard, Pausable { address public immutable timelock; uint256 public totalObras; uint256 public fondosComprometidosEnObras; mapping(uint256 => Obra) public obras; mapping(uint256 => uint256) public expensasPagadasPorUnidad; mapping(address => uint256) public expensasPagadasPorVecino; modifier onlyTimelock() { if (msg.sender != timelock) revert SoloTimelockAutorizado(...); _; } function pagarExpensas(uint256 unidadId, string calldata concepto) external payable whenNotPaused { if (unidadId == 0) revert UnidadInvalida(); if (msg.value == 0) revert MontoInvalido(); expensasPagadasPorUnidad[unidadId] += msg.value; expensasPagadasPorVecino[msg.sender] += msg.value; emit ExpensasRecibidas(msg.sender, unidadId, msg.value, concepto); } function aprobarObraYLiberarHito1(...) external onlyTimelock whenNotPaused nonReentrant returns (uint256) { obraId = _crearObraInterna(...); _liberarHito1Interno(obraId); } }

Function Selectors:

  • pagarExpensas(uint256,string) → 0x4d51c3e1
  • aprobarObraYLiberarHito1(string,string,address,uint256) → 0x4f3a9c4d
  • rendirCuentasHito1(uint256,string) → 0x4d7f2c9b
  • liberarHito2(uint256) → 0xd5a4b9c1

Patrón CEI estricto: En liberarHito1/2/3 se actualiza estado (Effects) y se emite el evento ANTES de la llamada externa .call{value: monto}("").

onlyTimelock: El modificador compara msg.sender con el timelock inmutable. Cualquier intento de llamar directamente desde una EOA revierte con SoloTimelockAutorizado.

Gas Hito 1 (30%):

  • SSTORE × 7 (crear Obra struct, totalObras, fondosComprometidos): ~140k gas
  • SSTORE actualizar estado y montoLiberado: ~5k (warm)
  • CALL con ETH: ~10k base + transferencia
  • Total: ~160k gas + 21k base = ~180k gas

Reembolso por cancelación: Si cancelarObra() reduce fondosComprometidosEnObras pero no transfiere ETH, solo hace SSTORE (~100 gas + reembolso 4800 si slot a 0).
